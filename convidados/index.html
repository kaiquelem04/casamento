    Modo edição

    Para marcar presenças e mexer na lista por aqui, o GitHub pede uma chave de acesso. Ela fica salva só neste aparelho.

    1. Abra a página de criar chave no GitHub.
    2. Dê um nome (ex.: lista de convidados) e, em Expiration, escolha uma data depois do casamento.
    3. Em Repository access, marque Only select repositories e escolha casamento.
    4. Em Permissions, adicione Contents com acesso Read and write.
